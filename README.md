# tic-tac-toe
A simple, fully functional Tic Tac Toe game built with HTML, CSS, and JavaScript.
## How to Play
1. Open `index.html` in your browser (or visit the live GitHub Pages link below).
2. Player X goes first, followed by Player O.
3. Click any empty cell to place your mark.
4. The first player to get 3 in a row wins.
5. Click "Restart Game" to play again.
